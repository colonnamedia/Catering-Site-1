# Catering-Site-1

Reusable FireWorks catering website template.

## Local preview

Serve the repository root with any static web server, for example:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Safety

This is a fictional sample website. Its inquiry validates only in the browser and does not send, store, book or take payment.

See `FIREWORKS-PROJECT.md` for scope, pricing, integrations and launch requirements.
